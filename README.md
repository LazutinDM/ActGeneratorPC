# ActGeneratorPC

Полнофункциональная portable-версия ActGeneratorPC. Версия приложения: `1.0.22`.
Она использует собственные `Data`, `Acts`, Excel и настройки.

Дополнительно реализованы независимые режимы предпросмотра, массовой генерации
и локальной истории. Предпросмотр и массовая генерация выключены по умолчанию.
Для шаблона MID/Валидатор форма показывает период оказания услуги: начало и
окончание вводятся как `ЧЧ:ММ`, а дата автоматически берётся из основного поля
«Дата» и переносится в строку акта.
Для каждого созданного DOCX история сохраняет отдельный JSON-файл в
`Data/Other/History`; выбранный акт открывается как настоящий DOCX. Если DOCX
удалён из папки `Acts`, он исчезает из списка при обновлении истории.

Основная форма и закреплённая панель действий оформлены отдельными карточками;
светлая и тёмная темы используют одинаковую компоновку. В интерфейсе сохранён
оригинальный пользовательский набор цветных иконок из `Data/Icons`.
Кнопка `Акт по фамилии` создаёт чистый DOCX выбранного типа: программа приводит
исполнителя к единому формату `Фамилия И. О.`, очищает остальные поля и не
добавляет пустую строку в Excel. В меню кнопки доступны шаблоны `АБП / МКТФ` и
`Валидатор / МИД`. Поля периода услуги оставлены для ручного ввода `ЧЧ:ММ` без
видимых кнопок со стрелками.
Все дополнительные режимы включаются через меню `Файл`; отдельной кнопки
`Режимы` на верхней панели нет. Видимое название приложения — `Генератор актов`.

Portable-приложение Windows для создания актов DOCX. Установка не требуется:
рядом с `ActGeneratorPC.exe` должна находиться папка `Data`.

## Как устроен проект

- `app.py` — окна, поля формы, предпросмотр и создание актов.
- `app_paths.py` — единое описание portable-папок и файлов.
- `docx_preview.py` — экспорт временного DOCX в PDF для постраничного просмотра.
- `excel_export.py` — безопасное добавление данных акта во встроенную или выбранную XLSX-книгу.
- `update_manager.py` — проверка Release, скачивание, резервная копия и откат.
- `version.py` — текущая версия приложения.
- `Data/Templates` — шаблоны Word и исходный шаблон `Tables.xlsx`.
- `Data/Variables` — редактируемые списки полей.
- `Data/Icons` — постоянные иконки интерфейса.
- `Data/Other/Configuration` — настройки и ссылки.
- `Acts` — созданные пользователем документы; обновление её не удаляет.
- `tests` — проверки безопасной распаковки и отката обновления.

## Где вносить изменения

- Новый путь или папка: `app_paths.py`.
- Новое поле формы или визуальное изменение: `app.py`.
- Логика обновления: `update_manager.py` и обязательно тесты.
- Новый вариант списка: соответствующий TXT в `Data/Variables`.

## Запуск и проверка

```powershell
python -m pip install -r requirements.txt
python app.py
python -m unittest discover -s tests -v
```

Для визуального предпросмотра нужен установленный Microsoft Word или
LibreOffice. Приложение создаёт временный PDF и показывает его внутри окна;
сам PDF после закрытия предпросмотра не сохраняется.

При первом запуске приложение создаёт рабочую Excel-книгу
`Data/Other/Excel/Tables.xlsx` из встроенного шаблона. После подтверждения акта
оно заполняет первую свободную строку листа соответствующего месяца. Через меню
`Файл` можно открыть рабочую книгу, выбрать другую либо вернуться к встроенной.
Столбцы `Проверил`, `Наличие акта` и `Заявка` не меняются. `Участок` определяется
по станции, а `Примечания` заполняются правилом из `excel_export.py`.
Перед записью создаётся файл `*.xlsx.before-actgenerator.bak`. Обновление программы
не перезаписывает рабочую книгу в `Data/Other/Excel`.

Правая панель массового создания включается через
`Файл → Панель массового создания актов`. Заполните основную форму, добавьте
текущий акт в табличную очередь, затем измените данные для следующего акта.
Строки можно дублировать, удалять и загружать обратно в форму двойным щелчком
для редактирования. Команда `Создать все акты` показывает общий прогресс и
сохраняет очередь без открытия отдельного предпросмотра для каждого документа;
после завершения в таблице остаются только позиции с ошибками.
Кнопка `Очистить очередь` удаляет позиции только после подтверждения и не
затрагивает уже созданные документы.

В панели истории кнопка `Очистить историю` скрывает все текущие записи после
подтверждения. Файлы DOCX в папке `Acts` при этом не удаляются.
Кнопка `Удалить выбранный` действует только на выделенную строку: DOCX
перемещается в Корзину Windows, а его запись удаляется из истории.

## Памятка для коллег

- Подробное описание устройства, потоков данных и безопасных изменений находится
  в `COLLEAGUE_GUIDE.md`.
- Все безопасные точки настройки помечены `COLLEAGUE EDIT POINT`.
- Форма, меню, цвета, исключённые исполнители и размеры находятся в `app.py`.
- Пути, иконки, текстовые списки и DOCX-шаблоны задаются в `app_paths.py`.
- Excel-колонки, участки и правила примечаний находятся в `excel_export.py`.
- Версия задаётся в `version.py`, имена сборки — в `build.ps1` и `ActGeneratorPC.spec`.
- Репозиторий, имя ZIP и автопроверка задаются в `update_config.json`; JSON не поддерживает комментарии.
- Правило примечания задают `MATERIAL_NOTE_TRIGGER` и `MATERIAL_NOTE_TEXT`.
- Пути portable собраны в `app_paths.py`; не добавляйте абсолютные пути диска `X:`.
- Runtime PyInstaller штатно собирается внутрь `Data`. Не переносите DLL вручную:
  EXE хранит относительный путь к runtime в своём заголовке.
- После изменения логики добавьте тест в `tests` и запустите команду проверки ниже.

## Сборка portable

Для совместимости с рабочими Windows-компьютерами сборка выполняется строго на
Официальный Windows Python `3.12.10`; версии PySide6 и PyInstaller закреплены в requirements-файлах.

```powershell
.\build.ps1 -SkipInstall
```

Результат находится в `dist`. Папки `build`, `dist`, `.idea`, `__pycache__`
являются временными и не должны попадать в Git.

## Обновление

Обновление заменяет весь программный состав portable-архива, поэтому старые
служебные файлы автоматически исчезают. Пользовательские `Acts`, списки
`Data/Variables`, конфигурация и рабочая Excel-книга сохраняются. Перед заменой создаётся резервная
копия; если новая версия не подтверждает успешный запуск, выполняется откат.
